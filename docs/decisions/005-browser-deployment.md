# Decision 005: independent browser inference demo

A PC-hosted tunnel stops serving when the machine sleeps and is a poor primary resume link.
The selected managed backend account requested payment information, which violates the no-card constraint.

Export the small synthetic bundle into an exact JavaScript inference engine on GitHub Pages.
Keep the full FastAPI/FAISS/Docker platform reproducible separately. Port the actual projection,
ALS fold-in, ranking features, and tree predictions; gate publishing on Python numerical parity
and browser interaction tests. Keep synthetic demo data separate from real-data aggregate evidence.

Tradeoffs: the public model is downloadable, search is exhaustive, feedback is local, and backend
operational features are not hosted by Pages. This is acceptable for a public synthetic portfolio
fixture, but unsuitable for private model/data deployment. Zero ALS fold-in signal falls back to
content so cold onboarding does not produce arbitrary ties.
