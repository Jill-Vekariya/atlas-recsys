# Permanent GitHub Pages recommendation lab

Live lab: https://jill-vekariya.github.io/atlas-recsys/

The browser serves recommendations from the synthetic bundle's learned user projection,
item vectors, ALS factors, popularity scores, and 60 exported LightGBM trees. It uses exact
catalog search over 300 items. FAISS and its HNSW index remain in the Python backend.

The exporter checks the source bundle's asset checksums and permits only synthetic catalogs.
No raw Amazon/MovieLens histories, API keys, or account credentials are published. Aggregate
real-data reports are displayed in the Evidence tab. Scores are relative signals, not probabilities.

ALS folds in the selected history with a regularized solve. A zero-signal history falls back to
content similarity, including onboarding categories whose seed items have no collaborative
training signal. Likes and skips update a browser session's history/exclusions; they do not
retrain weights. Feedback stays in localStorage and can be reset per profile.

## Reproduce and verify

From the repository root, with Python 3.12 and uv:

```bash
uv sync --frozen --extra dev
uv run atlas smoke --config configs/smoke.yaml
uv run python scripts/export_browser_bundle.py
cd web
npm ci --no-audit --no-fund
npm test
npx playwright install chromium
npm run test:ui
```

On Windows with Chrome installed, set `ATLAS_BROWSER_CHANNEL=chrome` to use Chrome for UI tests.
Set `ATLAS_DEMO_URL=https://jill-vekariya.github.io/atlas-recsys/` to check the deployed site.
The default UI test server mirrors the `/atlas-recsys/` project prefix.

Five tests check projection, retrieval, ALS fold-in, ranking features/tree predictions, and
serving protocol. Four browser tests exercise profile/new-user selection, all algorithms,
held-out/category filters, local feedback and reset, evidence/provenance, and mobile layout.
Fixtures contain independent NumPy/LightGBM outputs; they are not generated by the JS engine.

`.github/workflows/pages.yml` runs numerical and Chromium checks before publishing static
files. Its verification artifact records maximum prediction differences. The synthetic model
is intentionally small; browser timing is device-specific and is not the measured FastAPI p95.

## Scope

GitHub Pages hosts no Python process, authenticated API, shared SQLite feedback, Prometheus
metrics, or model-registry rollout. Those capabilities are implemented in Docker. This deployment
is a portable inference demo with permanent source/evidence links, rather than a backend proxy
that stops working when the owner's PC sleeps.
