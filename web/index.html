ONE PROJECT, TWO SERVING PATHS

Small enough to inspect.
Complete enough to defend.

The free GitHub demo executes exported model parameters. The Docker backend covers API serving and operational behavior.

A

Browser demonstration

GitHub Pages hosts the app and synthetic model bundle. JavaScript computes history features, two-tower projections, exact retrieval, ALS fold-in, and LightGBM tree scores.

  • No account, card, or running PC needed
  • No API keys or external inference calls
  • Feedback stored only on your device
  • Numerical checks against Python reference outputs
Inspect browser inference ↗
B

Docker serving platform

FastAPI and FAISS serve verified bundles behind Caddy. Streamlit supplies the API-backed lab, while SQLite separates exposures from feedback.

  • API authentication and Prometheus metrics
  • FAISS exact and HNSW retrieval
  • Idempotent feedback and persistent volumes
  • Canary assignment, guardrails, and rollback

Model provenance

Exact browser retrieval replaces HNSW for this 300-item catalog. Deterministic tie handling and floating-point reductions can alter near-tied ordering. This demo does not establish production scale, online business lift, or public API latency.
